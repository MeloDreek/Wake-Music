あなたの音楽を、ずっと楽しめるコレクションに。

Wakemusic は、端末、クラウド、NAS、Navidrome にある音楽を再生・整理できるプレーヤーです。お気に入りの一曲から大切に集めたライブラリまで、自分らしい聴き方を。

◆◆◆ ローカルの音楽を、いつでも

1. MP3、FLAC、WAV、M4A、AAC、APE、AIFF、DSF、DFF などに対応。普段使いからロスレス音源のコレクションまで楽しめます。
2. ファイルやフォルダ、Wi-Fi 転送で音楽を読み込み。動画から音声を抽出することもできます。
3. 曲、アーティスト、アルバム、ジャンルから探して、プレイリストやお気に入りにまとめましょう。
4. ダウンロードした曲はオフライン再生に対応。通勤や旅行中も、通信環境を気にせず聴けます。

◆◆◆ 音楽の保存先につながる

1. Google Drive、Dropbox、Box、pCloud、MEGA、Baidu Netdisk、Aliyun Drive、115、123、Guangya のクラウドストレージに接続。
2. SMB、WebDAV、FTP で NAS、パソコン、サーバーの音楽にアクセス。
3. ストリーミング再生も、ダウンロードキューに追加してオフライン保存することも可能です。
4. 事前ダウンロードを有効にすると、再生中にダウンロードが完了した曲をローカルの音楽フォルダに保存します。

◆◆◆ 自分だけの音楽サーバー

1. 専用モードで Navidrome や互換性のある Subsonic サービスを利用できます。
2. 最近再生した曲、お気に入り、プレイリスト、ランダムな選曲、最近追加した曲から音楽を発見。
3. 曲、アーティスト、アルバムを閲覧・検索。サーバーが提供するアルバム情報、アーティスト紹介、似ているアーティストも表示します。
4. 曲をダウンロードしてクラシックモードに切り替えれば、そのままオフラインで楽しめます。

◆◆◆ 聴くだけでなく、丁寧に整理

1. 音声フィンガープリント認識で曲の情報を検索し、手作業を減らせます。
2. タイトル、アーティスト、アルバム、ジャケット、歌詞を編集。
3. 対応する音声ファイルにはメタデータを直接埋め込めます。端末やプレーヤーが変わっても、整理した情報はファイルとともに残ります。
4. 認識結果と書き込めるタグは、曲やファイル形式によって異なります。

◆◆◆ 音を調整し、特徴を見る

1. 10 バンド EQ とプリアンプゲインで、好みの音に調整。
2. 低音強調、ボーカル、ロック、ジャズなどのプリセットや、自分で保存した設定を選べます。
3. ローカル音源のスペクトルを分析し、形式、ファイルサイズ、平均ビットレート、サンプルレートを確認。
4. 分析結果をカードとして保存・共有できます。スペクトルは音の特徴を知る手がかりですが、それだけで真のロスレス音源かどうかは証明できません。

◆◆◆ 聴く時間を、自分らしく

1. レコードやカセットなどのプレーヤースタイルを選択。
2. ジャケットに合わせた背景、ミニ歌詞、音声情報を表示。
3. シャッフル、順番再生、1 曲リピート、再生キュー管理、スリープタイマーに対応。

◆◆◆ プレミアムと購入について

1. リモート接続や EQ 調整など、一部の機能にはプレミアムが必要です。詳しくはアプリ内をご確認ください。
2. 月額・年額サブスクリプション、個人向け買い切り、ファミリー共有対応の買い切りプランを選べます。
3. 無料トライアルがある場合、対象条件、期間、終了後の料金は購入画面に表示されます。
4. サブスクリプションは自動更新され、Apple Account のサブスクリプション設定で管理・解約できます。買い切りプランの自動更新はありません。
