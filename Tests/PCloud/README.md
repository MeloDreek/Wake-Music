# pCloud 接入验证

当前 UIKit / Mac Catalyst 架构内实现，不改动 KSPlayer 或其他网盘 SDK，不涉及未来重构。

## 自动检查

在项目根目录运行：

```sh
bash Tests/PCloud/run-model-regressions.sh
bash Tests/PCloud/run-status-regressions.sh
```

直接编译仓库内的 SmartCodable、音频格式枚举和 pCloud 模型，执行 23 项检查。无网络请求，不读取任何真实账号、不初始化 App 或访问音乐库。构建产物保留在临时目录。

本次检查：23 项模型检查通过；iOS Simulator 普通版 / Pro 版构建通过。Mac Catalyst 构建被仓库现有 `IQKeyboardReturnManager` 的兼容性错误阻挡（Xcode 26.6 下的 `UIInputSuggestion`、`UITextFormattingViewController` 可用性错误），未改动该依赖，也未将 Mac 整包标记为验证通过。

## 需要真实账号的验收

- 普通版 / Pro 版分别在 iOS、Mac Catalyst 从“导入”和“连接”进入 pCloud。取消授权不应新增账号或弹出失败提示。
- 分别连接美国区、欧洲区账号。确认邮箱、根目录、至少两层子目录正确；重启 App 后仍可浏览。
- 在同一目录反复刷新，不应重复；测试空目录、无搜索结果、中文 / 空格 / `#` 文件名和 `.FLAC` 等大写后缀。
- 开启 / 关闭分组后检查排序、全选 / 取消选择、批量下载；文件夹和非音频不能进入音频下载队列。Mac 可从右上角菜单刷新。
- 分别使用系统引擎及 KSPlayer 播放支持的格式，测试上一首 / 下一首、拖动、暂停 / 继续、后台播放；连续快速切换 A→B→A、取链接期间暂停或停止，不应被旧请求重新启动。
- 开启预下载，验证下一曲缓存可播放；不同账号 / 目录中的同名文件不得串歌。显式下载保留原文件名；遇到本地重名时添加数字后缀，不覆盖原文件，可从本地音乐库离线播放。远程条目只自动命中按账号和文件 ID 隔离的预下载缓存，不按同名猜测用户本地文件。
- 在播放页收藏 / 取消收藏，重启后核对。网盘行的下载按钮不再弹出菜单，点击后选择保存位置并加入下载队列；不再提供云端音乐标签页面，下载后的本地文件仍可编辑标签。既有会员与播放格式限制保持不变。
- 撤销账号授权后刷新目录，应提示重新登录；重新授权只能登录原账号，取消后不改变原连接。播放 / 下载授权失败会给出提示，可回到该账号目录刷新并重新授权。
- 删除一个账号，只移除该账号的授权、连接、收藏和播放队列；其他账号继续可用，已显式下载的本地音乐保留。
- 断网、文件被删除、权限不足、下载失败时不能无限加载或把错误页当成下载成功。

## 配置与范围

- 使用 `AppGroupConstKey` 中已有的 `pCloud_AppID`；两个 App 的 URL Scheme 已对齐 SDK 生成的小写值 `pclsdk-w-a7jnl6xfok4`。若授权平台报回调地址不匹配，需要在 pCloud 开发者后台核对该 App 的注册回调。
- OAuth 令牌保存在按 App、区域、账号隔离的 Keychain 项中；普通版与 Pro 版各自授权。App Group 中只持久化账号身份、区域和文件元数据。
- 使用授权结果中的数据中心，并校验区域与官方 API 主机匹配。文件播放 / 下载链接按需获取，不把临时链接当永久地址。
- 支持常规 pCloud 文件空间，不包含 pCloud Crypto 客户端解密、云端上传 / 删除 / 标签回写，也不新增云端图片 / 视频预览。
- 新 App 文件已加入 Mobie、Mobie_Pro 两个 target；共享模型已加入现有 AppGroupKit Pod 工程。没有执行 `pod update` 或更改依赖版本。

自动模型检查与构建通过不等同于真实账号联调；以上授权、网络与音频验收仍需实测。

## 专属目录限制与空列表提示（2026-09-11）

- 当前 pCloud 应用后台为 `Specific folder only` + `Read only`。真实账号已验证：`Applications/Wake Music` 为空时列表为空；将一首测试 MP3 复制进去后，现有授权可直接列举并播放。网页的 Audio 分类并不是可选的 OAuth 目录。
- 根目录加载成功但为空时，说明只读访问范围、真实目录路径，以及通过 pCloud 网页或客户端添加音乐后刷新。不要把普通空目录说成授权或网络错误。
- 空子文件夹提示添加音乐；搜索无结果提示更换搜索词，按钮清除搜索；实际请求失败仍显示原错误和重试。
- 提示使用可滚动布局，避开安全区域、迷你播放器和键盘，支持动态字体。人工验收覆盖小屏、横屏、大字体、中英文与从右到左语言。
- 新增三条提示覆盖英语源文案及现有 41 个本地化地区；同时修正已有 `Refresh` 在多种语言中误译为“脸红／冲洗”的问题。
- `run-status-regressions.sh` 编译真实状态逻辑，检查根目录／子目录／搜索／失败分流、本地化完整性与路径占位符，不访问真实账号。
- 日后 pCloud 批准扩大访问范围时，需要同步调整 `PCloudFileListEmptyState.appFolderMessage`，不能继续向全盘授权用户展示当前限制说明。
